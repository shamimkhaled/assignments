# 🚀 Student Performance Analysis System Guide

A simple guide to analyze student performance data using Google Colab.

---

## 📋 What You'll Need

Before starting, prepare these files:
1. **`.ipynb` file** - The Jupyter notebook
2. **`student_performance_analysis.py`** - Main program script
3. **Campus Data Files** - Text files like `CMP001.txt`, `CMP002.txt`, etc.

---

## 🔧 Getting Started: Upload Your Notebook

### Open in Google Colab:
1. Go to [colab.research.google.com](https://colab.research.google.com)
2. Sign in with your Google account
3. Click **File** → **Upload notebook**
4. Choose your `.ipynb` file or drag and drop it
5. Wait for upload to complete - the notebook opens automatically

---

## ▶️ Running the Analysis

**How to run cells:** Click the Play button (▶️) or press `Shift + Enter`  
**Important:** Always run cells in order!

### Step 1: Set Up Directories
Creates folders for organizing your files.

### Step 2: Upload Your Files
Click "Choose Files" and select `student_performance_analysis.py` and all `CMP*.txt` files at once.

### Step 3: Verify Files
Confirms all files uploaded correctly.

### Step 4: Import Module
Prepares the analysis script.

### Step 5: Run Analysis
Processes all campus data and generates reports.

### Step 6: View Statistics
Shows overall performance across all campuses.

### Step 7: Campus Breakdown
Displays individual campus details and at-risk students.

### Step 8: Generate Report
Creates comprehensive academic performance report.

### Step 9: View Report
Displays the full report content.

### Step 10: Search Report
Search for keywords in the report.

### Step 11: Download Results
Downloads a zip file with all generated reports to your computer.

---

## 💡 Quick Tips

- **Run all cells:** Menu → `Runtime` → `Run all`
- **Start fresh:** Menu → `Runtime` → `Restart runtime`
- **Save your work:** Menu → `File` → `Save a copy in Drive`
